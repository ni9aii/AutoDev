The tree is generated by `tools/gen-structure.sh` (run via `bash tools/gen.sh`)
and drift-checked in CI — do not edit the block by hand.

Top-level layout:

| Path | Contents |
|------|----------|
| `src/` | Library (`src/lib.rs`, one module per file) + binaries under `src/bin/` |
| `src/bin/run_pipeline/` | Pipeline orchestrator: thin `main.rs`, phases in `phases/`, dispatch in `pipeline/` |
| `tests/` | Per-feature integration tests + shared fixtures in `tests/common/mod.rs` |
| `harnesses/` | Per-harness overlay files for skill rendering |
| `references/` | Canonical deep-dive docs, symlinked into rendered skill dirs |
| `skills/<harness>/` | Rendered per-harness SKILL.md surfaces (generated) |
| `docs/` | User documentation |
| `examples/` | Worked sample: reports → plan → JSON summary |
| `tools/` | Generators (`gen.sh`, `gen-structure.sh`) |
